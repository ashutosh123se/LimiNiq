# Hero video (optional)

Drop an AI-generated looping showreel here to match Digital Heroes–style muted background video:

- `hero.mp4` (required for video mode)
- `hero.webm` (optional, preferred on Chromium)

Recommended: 8–15s seamless loop, 1920×1080 or 1280×720, muted, no loud cuts.
Tools: Runway, Kling, Pika, Luma Dream Machine, etc.

Until a file exists, the site uses the cinematic network canvas + poster at `/images/hero/poster.png`.
